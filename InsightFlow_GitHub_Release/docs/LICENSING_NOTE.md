# Licensing decision

No standard open-source license is included yet. A public GitHub repository can be viewed and forked through GitHub's interface, but that does not automatically give everyone permission to reuse the code under an open-source license.

Before adding a license, confirm your university's ownership/submission policy and decide whether you want to use a permissive license (for example MIT) or keep all rights reserved. Do not add a license text without making that decision.
